<h1 align="center">fufuDown</h1>

<p align="center">校园工程软件的下载中心与 Windows 下载器</p>

<p align="center">
  <a href="https://github.com/dubstefu/fufuDown/releases/download/preview/fufuDown.exe"><strong>下载 Windows 测试版</strong></a>
  · <a href="https://down.dubstefu.com/">打开网页软件库</a>
</p>

fufuDown 把 PCB 设计、电路仿真和 STM32 开发工具放进一个软件库。可以直接从网页下载安装包，也可以用 Windows 下载器保存原包，再按需打开安装向导。

## 怎么用

- **只想拿安装包**：打开网页软件库，找到所需软件并点「下载」。按页面提示完成校内验证。
- **希望下载后继续安装**：运行 `fufuDown.exe`，从列表选择一款软件，再选「仅下载」「下载并安装」或「下载后打开向导」。按钮随软件支持的方式显示。
- **已经下载过**：在「已下载」里找到原安装包，通过下载器打开安装程序或定位文件。

Windows 下载器适用于 **Windows 10 / 11 x64**。当前为未做 Windows 代码签名的测试版。

## 软件库

| 用途 | 软件 |
| --- | --- |
| 原理图与 PCB | 嘉立创 EDA 专业版、Altium Designer、KiCad |
| 电路仿真 | NI Multisim |
| STM32 开发 | STM32CubeMX、STM32CubeIDE、STM32CubeProgrammer |

软件按需逐项下载，安装由使用者选择。Altium Designer 使用官方在线安装向导。各软件的账号、许可与激活在厂商向导或应用内完成。
